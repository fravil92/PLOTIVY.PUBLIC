## What is PLOTIVY?

PLOTIVY is a modern, AI-powered scientific data visualization platform that eliminates the friction between raw data and publication-ready plots. Designed specifically for researchers, engineers, and data scientists, PLOTIVY combines the power of AI code generation with intuitive data exploration, enabling you to:

*   **Describe plots in natural language** → Get instant Python code and high-resolution figures
*   **Work with your data privately** → Zero data retention policies with premium AI models
*   **Create reproducible research** → Export figures with full code history and metadata
*   **Design experiments smarter** → Built-in Design of Experiments (DOE) tools for statistical planning
*   **Collaborate effortlessly** → Share plots, analyses, and workflows with your research team

PLOTIVY is not a black box. Every visualization is generated with fully reviewable, version-controlled Python code—ensuring your research is transparent, reproducible, and publication-ready for decades.

## Key Features

### 1. AI-Accelerated Scientific Plotting
Upload CSV, Excel, or JSON data and describe what you want to visualize in plain English. PLOTIVY turns your natural language instructions into precise Python code that generates publication-quality plots instantly.

*   **You say:** "Create a scatter plot of absorption vs temperature with error bars, colored by sample type, and add a linear fit line."
*   **PLOTIVY generates:** Matplotlib/Plotly code, high-resolution PNG/SVG, and a summary table.

**Supported Plot Types:**
*   **Static Plots**: Scatter, line, bar, histogram, box plots, heatmaps, surface plots
*   **Interactive Dashboards**: 3D visualizations, maps, Plotly dashboards
*   **Animations**: Time-series animations, particle simulations, frame-by-frame visualizations

**Supported Data Formats:**
*   CSV, Excel (.xlsx, .xls), JSON, TSV, DAT files
*   Automatic column detection and type inference
*   Handles missing data and outliers intelligently

### 2. Full Code Transparency & Reproducibility
Never accept a plot you can't understand. Every figure comes with:
*   Editable Python code (matplotlib, seaborn, plotly)
*   Complete version history tracking all modifications
*   Export with full metadata: code, data, parameters, and reproducibility report
*   LaTeX integration for academic papers

### 3. Multi-Model AI Integration
Choose from multiple AI providers for code generation:
*   **OpenRouter (recommended)**: Access to GPT-4, Claude, Grok, Gemini—pay per use
*   **OpenAI API**: Direct integration with OpenAI's latest models
*   **Zero Data Retention (ZDR) Models**: Enterprise-grade privacy for confidential research

*Privacy Note: Free tier AI models may use data for training. Premium and enterprise models offer strict zero-retention policies.*

### 4. Design of Experiments (DOE) Module
Plan and execute experiments smarter:
*   Generate factorial, response surface, and Latin hypercube designs
*   Automated statistical analysis and optimization suggestions
*   Integration with your plotting workflow for immediate visualization

### 5. Research Gallery & Collaboration
*   Browse 50+ example datasets spanning photonics, materials science, biology, chemistry, physics, engineering, and more
*   Share plots publicly or privately with collaborators
*   Like and comment on community visualizations
*   Access publication-ready examples for your field

### 6. AI Code Copilot
*   Intelligent suggestions for plot improvements
*   Automatic detection of statistical patterns
*   LaTeX formula generation for annotations
*   Code optimization and best-practice recommendations

## Security & Privacy

### Data Privacy
*   **Local Processing:** All data uploads are processed in your browser session
*   **Zero Data Retention:** Premium AI models with strict zero-data-retention policies
*   **Encryption:** TLS 1.3 for all data in transit
*   **No Server Storage:** Raw data is never permanently stored on our servers

### Authentication & Authorization
*   **JWT Tokens:** Secure token-based authentication
*   **Role-Based Access Control:** User, researcher, admin, and enterprise roles
*   **Session Management:** Configurable token expiry and refresh policies
*   **Rate Limiting:** Per-user and per-API-key rate limits
